## По-русски

AutoCAD Plot Library сам находит рамки в пространстве модели, подбирает формат и ориентацию,
печатает все листы в один PDF с закладками и делает скан-копии документов.

- Каждая версия — отдельный [релиз](https://github.com/kdv94411-oss/AutoCADPlotLibrary-releases/releases):
  установщик `Setup_AutoCADPlotLibrary_v….exe` и список изменений в описании.
- Установка: скачайте установщик, закройте AutoCAD и запустите его. Установленный плагин обновляется сам.
- Сайт: https://clevercad.karpov.work · руководство: https://clevercad.karpov.work/manual.html
- Вся история изменений: https://clevercad.karpov.work/changelog.html
- Поддержка: support@karpov.work

## In English

AutoCAD Plot Library finds title-block frames in model space, picks the paper size and orientation,
prints all sheets into a single bookmarked PDF and creates scanned copies of documents.

- Each version is a separate [release](https://github.com/kdv94411-oss/AutoCADPlotLibrary-releases/releases):
  the `Setup_AutoCADPlotLibrary_v….exe` installer and the release notes in the description.
- Installation: download the installer, close AutoCAD and run it. An installed plug-in updates itself.
- Website: https://clevercad.karpov.work/en/ · user guide: https://clevercad.karpov.work/en/manual.html
- Full release notes: https://clevercad.karpov.work/en/changelog.html
- Support: support@karpov.work
